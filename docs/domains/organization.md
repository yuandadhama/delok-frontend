# Domain: organization

## What it solves

CRUD for organizations. Organizations are the top-level tenant; projects and members belong to them. API is slug-identified (`/api/organization/:slug`).

## Location

`src/domains/organization/` + views `src/views/orgs/*` + routes `app/(root)/orgs/*`

## Structure

```
organization/
  api/organization.service.ts   # list, create, getBySlug, update, delete
  components/
    CreateOrganizationModal.tsx, OrganizationCard.tsx, OrganizationList.tsx,
    OrganizationListSkeleton.tsx, OrganizationEmptyState.tsx, OrganizationsPanel.tsx,
    OrganizationSettings.tsx, OrganizationDangerZone.tsx
  hooks/
    useOrganizations.ts (query ["organizations"])
    useOrganization.ts  (query ["organization", slug])
  schemas/organization.schema.ts # name: 3-100, trimmed, no leading/trailing hyphen, no double hyphen
  types/organization.type.ts     # Organization {id, name, slug, createdAt, updatedAt}
  index.ts
```

## Functionality

- **List:** `GET /api/organization` -> `OrganizationList` / `OrganizationsOverview`
- **Create:** `POST /api/organization` -> `CreateOrganizationModal` (validates `organizationSchema`)
- **Get:** `GET /api/organization/:slug` -> `OrganizationPage`, `OrganizationSettingsView`
- **Update:** `PATCH /api/organization/:slug` -> `OrganizationSettings` (rename; slug regenerated by backend)
- **Delete:** `DELETE /api/organization/:slug` -> `OrganizationDangerZone` (cascades to projects, keys, members per service comment)

`normalizeOrganization` maps `created_at/updated_at` -> `createdAt/updatedAt`.

Error code `ORGANIZATION_SLUG_ALREADY_EXISTS` is mapped to "Organization name is unavailable".

## Dependencies

- External: `@tanstack/react-query`, `zod`, `fetch`
- Internal: `src/utils/api-error.ts`, `src/constants/routes.ts`
- Other domains: none

## Routes using it

- `/orgs` -> `OrganizationsPage` -> `useOrganizations`
- `/orgs/:slug` -> `OrganizationPage`
- `/orgs/:slug/settings` -> `OrganizationSettingsPage` -> `OrganizationSettings` + `DangerZone`
- `/orgs/:slug/projects` -> `ProjectsPage` (needs org slug to list projects)

## External systems

- Backend: `/api/organization/*` with cookie auth; OWNER role required for create/update/delete per service comments.

## Incomplete

- No member list / invite UI in frontend (backend may support it).
